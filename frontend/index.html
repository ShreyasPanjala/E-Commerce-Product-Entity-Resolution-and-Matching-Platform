How the Engine Works

THE RESOLUTION PIPELINE

Seven intelligent stages transform raw, fragmented listings into clean canonical product entities.

01
NORMALIZE
Remove irrelevant formatting differences — punctuation, casing, stop words, and whitespace noise.
02
TOKENIZE
Break product descriptions into meaningful atomic tokens for structural comparison.
03
BLOCK
Group candidates by shared key signals to avoid O(n²) exhaustive pairwise comparisons.
04
MATCH
Apply KMP, Rabin-Karp, Suffix Array, and Wagner-Fischer algorithms for multi-signal matching.
05
SCORE
Combine Jaccard token similarity, edit distance, and substring overlap into a composite confidence score.
06
CLUSTER
Use graph-based clustering to group all listings that refer to the same real-world product.
07
CANONICALIZE
Create one unified, authoritative product representation — the canonical entity — for clean catalog display.

Algorithm Intelligence

EIGHT ALGORITHMS.
ONE ENGINE.

Each algorithm contributes a distinct signal to the entity resolution confidence score.

String Search
KMP
Knuth-Morris-Pratt
Linear-time pattern matching using a failure function to skip redundant character comparisons.
O(n+m) time complexity
Rolling Hash
RK
Rabin-Karp
Hash-based substring search using rolling hash windows for efficient multi-pattern detection.
O(n+m) average case
Substring Analysis
SA
Suffix Array + LCP
Longest Common Prefix analysis over sorted suffixes to identify shared product token sequences.
O(n log n) construction
Edit Distance
WF
Wagner-Fischer
Dynamic programming computation of Levenshtein edit distance to measure character-level similarity.
O(n×m) DP table
Token Similarity
J
Jaccard Similarity
Set-theoretic overlap of token bags: |A∩B| / |A∪B| for robust, order-independent comparison.
|A∩B| / |A∪B| metric
Efficiency
BL
Blocking
Candidate pair reduction by partitioning the listing space using shared key features before full comparison.
O(n) → O(k) reduction
Graph Theory
GM
Graph Matching
Model listings as graph nodes with similarity-weighted edges, then resolve connected components into entity groups.
G(V,E) graph model
Entity Formation
CL
Clustering
Transitive closure over matched pairs groups all variant listings into one coherent canonical entity cluster.
Transitive closure
