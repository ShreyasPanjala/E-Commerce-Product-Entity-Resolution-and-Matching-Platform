Wagner-Fischer Dynamic Programming Edit Distance Table

Generates the complete 2D DP table. The backtracked optimal alignment path is highlighted in glowing emerald.

Time: O(M × N) • Space: O(M × N)
Recurrence Relation: DP[i][j] = (S₁[i-1] == S₂[j-1]) ? DP[i-1][j-1] : 1 + min(DP[i-1][j] (Del), DP[i][j-1] (Ins), DP[i-1][j-1] (Sub))

Knuth-Morris-Pratt (KMP) Prefix Function (π-Array)

Constructs the Longest Proper Prefix which is also a Suffix (LPS) table, enabling linear string search without backtracking.

Search: O(N) • Precompute: O(M)

Rabin-Karp Rolling Polynomial Hash Calculator

Demonstrates constant time O(1) hash updates across shifting character windows using modular polynomial arithmetic.

Average: O(N + M) • Space: O(1)
